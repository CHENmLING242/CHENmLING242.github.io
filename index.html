核心功能

八件事，管好你的零食仓库

从录入到提醒到比价，覆盖个人囤货的完整链路。所有功能离线可用，数据只存在本机。

立体收纳

同一商品的多个口味收进一个「卡片集册」，各自记保质期与价格，不再散落一地。

保质期排序

首页按剩余保质期升序，临期 / 紧急 / 已过期分级标注，最该先吃的排最前。

价格历史

改价只增不改，旧价保留。当前价、历史最低价、折线趋势随时可查，囤货心里有数。

同类别对比

饮料比饮料、零食比零食（2~4 项）。配料并集表 + 每 100g 营养归一化，最高红最低绿。

扫描录入

ML Kit 离线 OCR 识别包装，预填配料、营养、生产日期等，结果一律标「待校对」。

配料标记

内置规则词典标记添加剂、致过敏源、婴幼儿不适成分，紫 / 红 / 黄三色可叠加。

临期提醒

每日本地通知 + 回前台补精确清单 + 当天去重，不赌后台保活，到点就提醒。

备份迁移

整库 JSON 导出 / 导入，图片可选嵌入。经系统分享面板，换机数据可迁移，不主动上传。

核心业务规则

口径统一，处处一致

阈值、排序、换算、归一化都有明确定义，首页、详情、对比、提醒读同一套规则，不硬编码、不漂移。

保质期换算
月/年按日历，月末夹紧（1/31 + 1 月 → 2/28）；到期日录入时算好存下。
状态阈值
normal >90 / warning 31~90 / urgent 1~30 / expired ≤0，可在设置改，首页读设置。
排序
口味按剩余天数升序；集册按「最早到期口味」升序，最紧急的代表整册。
价格
当前价 = 最新一条；最低价 = 历史最小；改价只增不改，旧价永久保留。
营养归一化
统一到每 100g；每份基准用 值/serving_g×100；缺克数跳过而非补零。
对比约束
仅同类别；2~4 项；配料并集、营养最高红最低绿，跨类别直接拒绝。
标记优先级
婴幼儿不适(紫) > 致过敏源(红加粗) > 添加剂(黄底)，可叠加。
OCR 与提醒
OCR 结果必校对、失败不阻塞；提醒每日固定 + 回前台补内容 + 当天去重。
隐私与免责

你的数据，只在你手机里

本地优先不是一句口号：没有账号、没有服务器、没有上传。下面是数据去向与参考性功能的边界。

本地存储

全部数据存本机私有数据库与文件目录，不收集、不上传、不共享。卸载即清除，请提前备份。

离线识别

相机仅用于录入与识别，OCR 在本机离线完成，图片不会上传到任何服务器。

分享由你定

导出生成本地文件后调起系统分享面板，发到哪由你选，App 不主动发送任何数据。

⚠ 参考性功能免责声明

配料标记由保守规则词典匹配生成，必然存在遗漏、也可能误判；OCR 识别可能有误差；营养对比与保质期推算仅供横向参考。以上均不构成食用建议或食品安全保证。过敏体质人群、婴幼儿及特殊疾病患者，食用前务必以包装原文为准并咨询医生或专业人士。
